# 核心板块时间状态与影子评估实现记录

## 定位

本次新增层只做时间解释与研究性验证，不改变环境指数、流动性水位、盘后战术压力、
风险资本阶梯、动态异动脉冲的原始公式，也不连接正式告警或仓位逻辑。

## 第一阶段：每日时间状态

- `temporal_monitor.py` 从既有日表读取历史，统一输出当前水位、标准化风险值、
  1/5/21日风险变化、持续天数、状态转折、覆盖率、置信度和版本。
- 流动性支持与风险资本扩散反向映射到“越高越危险”的内部风险刻度；邮件继续展示
  原始业务刻度。
- 动态异动脉冲保留事件模型，不用移动平均制造连续分数；只统计滚动事件次数、方向、
  行业广度和持续性。
- 突然转折必须由另一个确认数据族同方向确认；环境指数与盘后战术压力共享
  VIX/MOVE/信用输入，属于同一族，不能互相重复确认。
- `temporal_report.py` 生成统一压力曲线和状态持续带，作为盘后邮件第三张PNG附件。

## 第二阶段：影子结果台账

- `temporal_state_daily.observation_mode` 明确区分 `REPLAY` 与 `LIVE_SHADOW`。
- `temporal_shadow_evaluation` 只在完整未来1/5/21个交易日已经存在时写入结果；保存
  QQQ/SPY未来收益、路径最大回撤、实现波动率和最大绝对跳空。
- 回放脚本默认dry-run，必须显式传入 `--write`；写库前先保护已有的实盘影子行。
- 历史回放不计入60日阶段审阅和120日完整周期。每个状态至少20个真实成熟结果后，
  才允许形成分状态统计；当前仍不接入告警或仓位。

## 已知边界

- 统一阈值是版本化影子规则，不是已经回测确认的交易阈值。
- 周频和月频分量仍由上游的来源日期与覆盖规则控制；时间层不会把填充日当作新的原生
  数据，但板块综合值仍可能随其他日频分量变化。
- 动态股票榜单存在选择偏差，历史候选不能从当前股票池倒推；只使用每日已归档候选。
- 数据库迁移、云端文件哈希、真实Supabase写入和下一次自然cron仍须分别验收。
