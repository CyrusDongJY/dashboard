# Intraday Breadth Contract Remediation - 2026-07-24

## Confirmed production evidence

- IBKR contract requests for `ADV-NYSE`, `DECL-NYSE`, `UVOL-NYSE` and
  `DVOL-NYSE` returned error 200: no security definition.
- The same read-only session resolved SPY, `TICK-NYSE` and `TRIN-NYSE`, ruling
  out a general Gateway or market-data outage.
- `AD-NYSE` resolved to conId 33887584, NYSE Advance Decline Index.
- IBKR symbol search returned no UVOL/DVOL index contract.
- Database rows from 2026-07-01 through 2026-07-16 contained zero raw
  UVOL/DVOL but a default `vol_ratio=1.00`; rows from 2026-07-20 onward
  correctly retained the raw zeros but published no ratio.

## Remediation contract

- `add_val` is sourced only from the qualified `AD-NYSE` contract.
- A qualified contract requires a positive conId; failures persist the IB error
  code and contract status.
- U/D remains NULL with `UNSUPPORTED_BY_IBKR_CONTRACT` until a separately
  licensed and validated source is integrated.
- Zero is valid for AD and TICK. Missing subscriptions and non-finite values are
  represented by NULL, never by zero or one.
- Historical rows generated by the invalid contracts are nulled and marked
  `LEGACY_INVALID_IBKR_CONTRACT` before reuse in research or alerts.

4. During RTH, verify `AD-NYSE` has a qualified conId and a non-missing stream.
5. Keep all U/D-dependent alerts disabled while the source status is
   `UNSUPPORTED_BY_IBKR_CONTRACT`.
