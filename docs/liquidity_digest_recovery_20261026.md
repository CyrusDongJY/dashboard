# 流动性与风险传导日报缺数修复

## 范围与根因

用户指定核查含网页/PDF的流动性汇总日报，并要求补数后重新发送。
本次不改变跨资产战术压力公式、权重或阈值，不重写原定时报告。

2026-10-26 09:20 ET原报告的股票收盘基准是2026-10-23。
主要发现：

1. 云端独立版本的VX标准月采集器将字符串
   `YYYYMMDD 16:00:00 America/New_York` 直接传给IB历史接口。
   实际探测两腿均返回错误10314和零根K线，继而被归为
   `NO_ALIGNED_CURRENT_DAY_TRADES`，使水位仪缺少必要分项。
   用带纽约时区的datetime对象，经ib_insync转换后，两腿各返回264根K线。
2. 核心资金新版本只有一条LIVE_SHADOW实测，原有PIT_REPLAY也只有一条。
   5日变化为空符合连续6点校验，但历史回放没有充分入库。
3. 本轮独立普通GET复核ICI返回HTTP403；ETF同日份额/NAV/公司行动尚未核验。
   这些不代表资金流为零，也不能用成交额、CFTC持仓或FINRA融资余额替代。
4. 部分同版历史窗口、固定成员广度历史不足，属于比较资格不足。
   不混接不同版本，不从文字日志猜测缺失战术分数。
